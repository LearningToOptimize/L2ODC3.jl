API reference

L2ODC3 — Module
L2ODC3

Learning-to-optimize methods that enforce hard constraints by completion and correction, built on L2OCore:

  • DC3: Deep Constraint Completion and Correction (Donti, Rolnick & Kolter, ICLR 2021). The proxy predicts the independent variables, an equality completion recovers the rest so that the equality constraints hold exactly, and unrolled gradient steps reduce the inequality violation.
  • FSNet: Feasibility-Seeking Neural Network (Nguyen & Donti, 2025). The proxy predicts every variable and unrolled gradient descent on the total violation ‖h‖² + ‖ReLU(g)‖² seeks a feasible point.

Problems are JuMP models with parameters wrapped as L2OCore.ParametricProblem; the package is framework-agnostic (any callable proxy, any ChainRules-compatible AD).

Methods

L2ODC3.DC3 — Type
DC3(; λ_ineq = 10.0, λ_eq = 10.0, penalty = :squared, train_steps = 10,
    test_steps = 10, step_size = nothing, momentum = 0.5, test_tol = 0.0,
    completion = :auto, dependent = nothing,
    newton_maxiter = 50, newton_tol = 1e-10)

Deep Constraint Completion and Correction (Donti, Rolnick & Kolter, ICLR 2021, arXiv:2104.12225), a primal method.

The proxy predicts the independent variables z (output_dimension(pipe) rows). complete(pipe, inputs, output) applies the equality completion φ_x (equality_completion) and test_steps correction steps (inequality_correction); loss(pipe, inputs, output) applies train_steps correction steps and returns the soft loss (eq. (2) of the paper)

\[\ell = \frac1B\sum_{k} f_x(\hat y_k) + \lambda_g \|\mathrm{ReLU}(g_x(\hat y_k))\|_2^2 + \lambda_h \|h_x(\hat y_k)\|_2^2 .\]

Keyword arguments:

  • λ_ineq, λ_eq: soft-loss weights λ_g, λ_h;
  • penalty: :squared (eq. (2) of the paper, default) or :norm, which uses ‖ReLU(g)‖₂ and ‖h‖₂ without squares as the reference implementation does (it also splits a total weight 10 as λ_g = λ_h = 5);
  • train_steps, test_steps: correction steps t_train, t_test;
  • step_size: correction step γ; nothing uses (1 - momentum)/L for affine problems (default_step_size), a step for which both plain gradient descent (momentum = 0) and heavy-ball momentum provably converge on the convex reduced violation; it must be given for nonlinear problems. (The paper fixes γ = 10⁻⁷ for its QPs, Appendix B.1.);
  • momentum: heavy-ball momentum μ of the correction (0.5 in the paper, Appendix B; the CorrectionDescent claim is stated for μ = 0);
  • test_tol: stop the test-time correction once max ReLU(g) ≤ test_tol (the paper's stopping tolerance is 10⁻⁴, Appendix B; 0 runs exactly t_test steps as in Algorithm 1);
  • completion: :auto (closed-form LinearCompletion when the equalities are affine, NewtonCompletion otherwise), :linear, :newton (forces the nonlinear form and Newton), or a function (problem, form) -> AbstractCompletion (extension point);
  • dependent: indices of the dependent variables (default: chosen by select_dependent);
  • newton_maxiter, newton_tol: Newton completion settings.

Guarantees: EqualityFeasible (to round-off for affine equalities; to newton_tol when Newton converges for nonlinear equalities). Supports LinearConic (box-like sets and second-order cones), ConvexQuadratic and SmoothNonlinear problems.

L2ODC3.FSNet — Type
FSNet(; ρ = 10.0, train_steps = 20, test_steps = 100, unroll = train_steps,
      step_size = nothing, penalty = 10.0, penalty_threshold = 1e3,
      test_tol = 0.0, solver = :gd, memory = 10)

Feasibility-Seeking Neural Network (Nguyen & Donti, 2025, arXiv:2506.00362), a primal method. The proxy predicts all decision variables y_θ(x); feasibility_seeking runs gradient descent on the violation φ = ‖h‖² + ‖ReLU(g)‖² from there, and the loss is (eq. (6) of the paper, with the early-stage penalty of Section 5)

\[F = f_x(\hat y) + \frac{\rho}{2}\|y_\theta(x) - \hat y\|_2^2 + \rho_\phi\, \phi(y_\theta(x))\,[\phi(y_\theta(x)) \ge Q].\]

Keyword arguments: ρ; train_steps (K) and unroll (K', derivatives flow through the first K' of the K iterations); test_steps; step_size (η_φ; nothing uses 1/L for affine problems); penalty (ρ_φ; 0 disables it) and penalty_threshold (Q); test_tol (early stop at test time). The defaults ρ = 10 (distance weight ρ/2 = 5), ρ_φ = 10 and Q = 10³ are those of the authors' reference configuration; the switch is evaluated per instance on φ(y_θ(x)), as in the paper's formula (the reference code switches on batch means).

solver = :gd (default) runs gradient descent with step η_φ, the setting of the paper's convergence theory (Theorem 1). solver = :lbfgs runs batched L-BFGS with memory curvature pairs and Armijo backtracking (feasibility_seeking_lbfgs), the inner solver of the paper's experiments; step_size is then only the first trial step (default 1/L for affine problems, 1 otherwise).

Guarantees: none for a finite number of steps (NoGuarantee); the FeasibilitySeekingDescent claim holds under the stated assumptions.

L2ODC3.soft_loss — Function
soft_loss(form, Y, P; λ_ineq, λ_eq, penalty = :squared) -> Real

Batch mean of the soft loss of eq. (2) of Donti et al., f_x(y) + λ_ineq ‖ReLU(g_x(y))‖²₂ + λ_eq ‖h_x(y)‖²₂ (objective in minimization form). With penalty = :norm the penalties are ‖ReLU(g_x(y))‖₂ and ‖h_x(y)‖₂ (not squared), as in the reference implementation of the paper; the norm is smoothed as sqrt(‖r‖² + ε²) with ε = eps(T) so that its gradient is finite at feasible points.

Problem forms

L2ODC3.AbstractProblemForm — Type
AbstractProblemForm <: L2OCore.AbstractEvaluator

Differentiable batch representation of a parametric problem used by DC3 and FSNet. A form is an L2OCore.AbstractEvaluator (it implements batch_objective, constraint_values, row_violation and equality_rows), and additionally provides

functionreturns
L2OCore.num_decision_variables(form)number of decision variables n (rows of Y)
row_bounds(form)(lower, upper), one entry per row
equality_indices(form) / inequality_indices(form)row indices of h and g
objective_sign(form)+1 (min) or -1 (max)
constraint_vjp(form, Y, P, W)J_y F(y_k, p_k)ᵀ W[:, k] for every column

All functions are batch-first (batch = last dimension) and differentiable with ChainRules-compatible reverse-mode AD (e.g. Zygote), including constraint_vjp, whose derivative needs second derivatives of F.

Built-in forms: AffineForm (dense arrays, GPU-ready) and NLPForm (JuMP nonlinear models through MOI.Nonlinear). A new backend (for instance batched GPU kernels generated from ExaModels) subtypes AbstractProblemForm and implements the functions above.

source
L2ODC3.AffineForm — Type
AffineForm(problem::L2OCore.ParametricProblem; T = Float64)
AffineForm(ev::L2OCore.MatrixEvaluator)

Dense matrix form of a problem with affine constraints and an (at most) quadratic objective, parameters entering affinely:

\[\min_y \; \tfrac12 y^\top Q y + c^\top y + y^\top H p + c_p^\top p + \tfrac12 p^\top Q_{pp} p + c_0 \quad\text{s.t.}\quad \ell \le A y + B p + b \le u .\]

Every operation is a dense matrix product or a broadcast, so the form runs unchanged on GPU arrays once its fields are moved with Adapt.adapt (see the package extension) and is differentiable by any array AD.

Assumptions: every constraint is a box-like set (EqualTo, GreaterThan, LessThan, Interval, Zeros, Nonnegatives, Nonpositives), a SecondOrderCone or a RotatedSecondOrderCone. Other cones (PSD, exponential, power) are rejected.

source
L2ODC3.NLPForm — Type
NLPForm(problem::L2OCore.ParametricProblem)

Form of a general smooth problem (nonlinear, quadratic or affine functions) built from the JuMP model with MathOptInterface.Nonlinear reverse-mode AD. Parameters are treated as extra evaluator variables, so derivatives with respect to the parameters come for free.

Batches are evaluated column by column on the CPU. Every function has a ChainRules rrule: batch_objective and constraint_values use gradients/Jacobians; constraint_vjp uses Hessian-of-the-Lagrangian products, so unrolled DC3 corrections are differentiated exactly.

Assumptions: twice continuously differentiable functions; box-like sets, second-order and rotated second-order cones (as for AffineForm); no legacy @NL macros. Not thread-safe (the form owns evaluation buffers).

L2ODC3.projection_residual — Function
projection_residual(form::AbstractProblemForm, F::AbstractMatrix) -> AbstractMatrix

F - Π_C(F) for every column of constraint values F (all rows), where C is the product of the constraint sets: intervals [ℓᵢ, uᵢ] for box-like rows and second-order cones for the blocks of cone_blocks. Equality rows give h, inequality rows give ReLU(g) (as a signed distance), and cone blocks give the cone residual. FSNet's violation is φ = ‖F - Π_C(F)‖², and its gradient with respect to F is 2(F - Π_C(F)).

L2ODC3.violation_indices — Function
violation_indices(form::AbstractProblemForm) -> AbstractVector{Int}

All inequality rows: the box inequalities (inequality_indices) and the rows of every cone block, sorted. These are the rows of inequality_residual. The fallback is inequality_indices(form).

L2ODC3.cone_blocks — Function
cone_blocks(form::AbstractProblemForm) -> Vector{Tuple{UnitRange{Int},Symbol}}

Rows of each conic constraint and its kind (:soc for MOI.SecondOrderCone, :rsoc for MOI.RotatedSecondOrderCone). Box-like rows are not listed. The fallback is an empty vector.

source
L2ODC3.soc_residual — Function
soc_residual(F::AbstractMatrix) -> AbstractMatrix

F - Π_K(F) for every column of F = [t; x] and the second-order cone K = {(t, x) : ‖x‖₂ ≤ t}. With α = (t + ‖x‖)/2, the projection is F if ‖x‖ ≤ t, 0 if ‖x‖ ≤ -t, and α (1, x/‖x‖) otherwise. Its squared norm is dist²(F, K) and 2(F - Π_K(F)) is the gradient of dist²(·, K).

Branch-free broadcasts (GPU-friendly). ‖x‖ is smoothed as sqrt(‖x‖² + eps²), so the derivative is finite at x = 0.

source
L2ODC3.rsoc_residual — Function
rsoc_residual(F::AbstractMatrix) -> AbstractMatrix

F - Π_K(F) for the rotated second-order cone K = {(t, u, x) : 2tu ≥ ‖x‖², t, u ≥ 0}, through the orthogonal map (t, u) ↦ ((t + u)/√2, (t - u)/√2) that sends it to the second-order cone.

source
L2ODC3.lipschitz_constant — Function
lipschitz_constant(form::AffineForm; rows = :all) -> Real

Lipschitz constant L = 2‖A_R‖₂² of the gradient of ‖F_R - Π(F_R)‖² on the rows R (:all constraint rows, :inequality (box inequalities and cone blocks, violation_indices) or :equality). It holds for cones too, since F ↦ F - Π_C(F) is 1-Lipschitz for any closed convex set. Gradient descent with step 1/L on that function never increases it (descent lemma); see the Theory page.

Equality completion z ↦ y = [z; φ_x(z)] of DC3. A completion implements

functionreturns
independent_indices(c)positions of z inside y
dependent_indices(c)positions of φ_x(z) inside y
equality_completion(c, Z, P)Y with h(Y, P) = 0 (differentiable in Z, P)
completion_pullback(c, Y, P, Ȳ)(∂y/∂z)ᵀ Ȳ (differentiable in Y, P, Ȳ)

Built-in: LinearCompletion (affine equalities, closed form) and NewtonCompletion (nonlinear equalities).

source
L2ODC3.LinearCompletion — Type
LinearCompletion(form::AffineForm; dependent = nothing, rtol = 1e-9)

Closed-form completion for affine equalities A_E y + B_E p + b_E = ℓ_E. With D the dependent and Z the independent columns,

\[y_D = -A_{E,D}^{-1}\,(A_{E,Z}\, z + B_E\, p + b_E - \ell_E),\]

which is precomputed as one affine map Y = K_z Z + K_p P + k_0 (n × n_z, n × n_p, n), so completion is a single batched matrix product (GPU-friendly) and its Jacobian ∂y/∂z = K_z is exact.

Redundant equality rows are removed (and checked to be consistent for every parameter value); dependent overrides the automatic choice (select_dependent).

source
L2ODC3.NewtonCompletion — Type
NewtonCompletion(form::NLPForm, problem; dependent = nothing, y0 = start values,
                 maxiter = 50, tol = 1e-10, rtol = 1e-9)

Completion for nonlinear equalities: for each instance, damped Newton's method on h_x([z; y_D]) = 0 in the dependent variables y_D, started from y0[D] (or from a warm start passed as init). Derivatives follow the implicit function theorem, eqs. (3)–(4) of Donti et al.: ∂y_D/∂z = -(J^h_D)⁻¹ J^h_Z and ∂y_D/∂p = -(J^h_D)⁻¹ J^h_p.

The dependent set is chosen by select_dependent on the equality Jacobian at (y0, p0) (start values and current parameter values) unless given.

Assumptions: h is C² near the solution; J^h_D is nonsingular there; the start point is in Newton's basin of attraction. Instances where Newton does not reach tol are returned as they are (the EqualityFeasible check reports them).

source
L2ODC3.select_dependent — Function
select_dependent(J::AbstractMatrix; rtol = 1e-9) -> (rows, dependent)

Choose a maximal set of linearly independent equality rows and as many dependent variables (columns of J) such that J[rows, dependent] is nonsingular, by QR with column pivoting (first on Jᵀ for the rows, then on J[rows, :] for the columns). Pivoting picks the best-conditioned columns greedily; the paper picks a random subset that gives a nonsingular block.

L2ODC3.completion_pullback — Function

Correction and feasibility seeking

L2ODC3.reduced_violation_gradient — Function
reduced_violation_gradient(form, completion, Y, P) -> ΔZ

Gradient of the inequality violation with respect to the independent variables, at completed points Y = [z; φ_x(z)]:

\[\Delta z = \nabla_z \big\|\mathrm{ReLU}\big(g_x([z;\varphi_x(z)])\big)\big\|_2^2 = \Big(\frac{\partial y}{\partial z}\Big)^{\!\top} J^g(y)^\top\, 2\,\mathrm{ReLU}(g_x(y)),\]

the correction direction of DC3 (Section 3.2 of Donti et al.). Computed with constraint_vjp and completion_pullback, so it is itself differentiable (needed to backpropagate through unrolled corrections).

source
L2ODC3.inequality_correction — Function
inequality_correction(form, completion, Z, P; steps, step_size, momentum = 0,
                      tol = 0) -> (Z, Y)

DC3's correction ρ_x^{(t)}: steps gradient steps on the inequality violation in the independent variables, with heavy-ball momentum as in the reference implementation,

\[v_{k+1} = \mu v_k + \Delta z_k,\qquad z_{k+1} = z_k - \gamma\, v_{k+1},\qquad y_{k+1} = [z_{k+1};\varphi_x(z_{k+1})],\]

where Δz_k is reduced_violation_gradient. Returns the corrected independent variables and the completed points.

Each iterate is re-completed. For affine equalities this is identical to the paper's step y - γ[Δz; (∂φ/∂z) Δz]; for nonlinear equalities the paper's step keeps the equalities only to first order, while re-completion keeps them to the Newton tolerance (a deliberate deviation).

tol > 0 stops early once every instance has max ReLU(g) ≤ tol (use at test time only; the stopping test is not differentiated).

Guarantee (CorrectionDescent, see the Theory page): if the reduced violation v(z) = ‖ReLU(g_x([z; φ_x(z)]))‖² has an L-Lipschitz gradient, momentum = 0 and 0 < step_size ≤ 1/L, then v(z_{k+1}) ≤ v(z_k) - (γ/2)‖Δz_k‖².

source
L2ODC3.violation_gradient — Function
violation_gradient(form, Y, P) -> AbstractMatrix

∇_y φ(y) for FSNet's violation φ(y) = ‖h_x(y)‖² + ‖ReLU(g_x(y))‖² (eq. (3) of Nguyen & Donti), i.e. J_yᵀ 2(F - Π(F)).

source
L2ODC3.feasibility_seeking — Function
feasibility_seeking(form, Y, P; steps, step_size, unroll = steps, tol = 0) -> Ŷ

FSNet's feasibility-seeking map FS truncated to steps gradient-descent iterations on φ(s) = ‖h_x(s)‖² + ‖ReLU(g_x(s))‖² started at the proxy output (eq. (4) of Nguyen & Donti, 2025):

\[s_0 = y_\theta(x),\qquad s_{k+1} = s_k - \eta_\phi \nabla_s \phi(s_k; x).\]

Derivatives flow through the first unroll iterations only (truncated unrolled differentiation, Section 5 of the paper); the remaining iterations contribute a constant offset. tol > 0 stops early once φ ≤ tol for every instance (not differentiated).

Guarantees (FeasibilitySeekingDescent): with φ L-smooth and 0 < η ≤ 1/L, φ(s_{k+1}) ≤ φ(s_k); if moreover φ satisfies the Polyak–Łojasiewicz inequality with constant μ and a feasible point exists, φ(s_k) ≤ (1 - μ/L)^k φ(s_0) (Theorem 1 of the paper). For affine constraints with a nonempty feasible set both assumptions hold (Hoffman's error bound), with L from lipschitz_constant.

source
L2ODC3.feasibility_seeking_lbfgs — Function
feasibility_seeking_lbfgs(form, Y, P; steps, unroll = steps, memory = 10,
                          step_size = 1, tol = 0) -> Ŷ

FSNet's feasibility-seeking map computed with L-BFGS, the inner solver used in the experiments of Nguyen & Donti (2025): steps iterations of the two-loop recursion with memory curvature pairs and Armijo backtracking on φ(s) = ‖h(s)‖² + ‖ReLU(g(s))‖², for every column independently. The first iteration starts from step_size (e.g. 1/L), later ones from a unit step.

Derivatives flow through the first unroll iterations; the line-search step lengths are treated as constants (as in the authors' implementation), and the remaining iterations add a constant offset (truncated unrolled differentiation).

Guarantee: Armijo backtracking makes φ non-increasing along the iterates.

source
L2ODC3.default_step_size — Function
default_step_size(form, completion) -> Real
default_step_size(form) -> Real

1/L, with L the Lipschitz constant of the gradient of the violation that is descended: the reduced inequality violation v(z) for DC3 (L = 2‖A_I K_z‖₂²) or FSNet's φ(y) (L = 2‖A‖₂²). Only defined for AffineForm; nonlinear problems need an explicit step_size. DC3 scales it by 1 - momentum (see DC3).

Other exported names

L2ODC3.CompletionJacobian — Type
CompletionJacobian()

Claim: the derivative used to backpropagate through the equality completion is the true derivative of the completion map, i.e. for directions u (in z) and v (in y), vᵀ (∂y/∂z) u computed with completion_pullback (implicit function theorem, eqs. (3)–(4) of Donti et al.) equals the central finite difference vᵀ (φ(z + εu) - φ(z - εu)) / 2ε.

Assumptions: h is C² and J^h_D is nonsingular at the completed points.

check(CompletionJacobian(), pipe, inputs, output; atol = 1e-5, ε = 1e-6, rng = Random.default_rng()) returns the relative error per instance.

source
L2ODC3.CorrectionDescent — Type
CorrectionDescent()

Claim (descent lemma): if the reduced inequality violation v(z) = ‖ReLU(g_x([z; φ_x(z)]))‖² has an L-Lipschitz gradient, every DC3 correction step without momentum and with 0 < γ ≤ 1/L satisfies v(z_{k+1}) ≤ v(z_k) - (γ/2) ‖∇v(z_k)‖² ≤ v(z_k).

For affine constraints, v(z) = dist²(Ĝz + ĥ(p), [ℓ, u]) with Ĝ = A_I K_z, which is convex with L = 2‖Ĝ‖₂², the default 1/L step of default_step_size.

check(CorrectionDescent(), pipe, inputs, output; steps = 20, atol = 1e-8) runs steps corrections with momentum 0 and the pipeline's step size, and reports per instance the largest relative increase of v (and of the sufficient-decrease bound).

source
L2ODC3.FeasibilitySeekingDescent — Type
FeasibilitySeekingDescent()

Claim (descent lemma, and Theorem 1 of Nguyen & Donti): if FSNet's violation φ(y) = ‖h(y)‖² + ‖ReLU(g(y))‖² has an L-Lipschitz gradient and 0 < η ≤ 1/L, every gradient step satisfies φ(s_{k+1}) ≤ φ(s_k) - (η/2)‖∇φ(s_k)‖². For affine constraints, φ is convex with L = 2‖A‖₂².

check(FeasibilitySeekingDescent(), pipe, inputs, output; steps = 20, atol = 1e-8) reports the largest relative violation of the sufficient-decrease inequality.

L2OCore.generate_data — Method
generate_data(method::Union{DC3,FSNet}, pipe; sampler, n, rng = Random.default_rng(),
              optimizer = nothing, kwargs...) -> L2ODataset

DC3 and FSNet are self-supervised: training needs only parameter samples. Without optimizer the dataset holds inputs only (no solver calls). With optimizer, every instance is also solved (L2OCore.solve_instances) so that the primal labels and optimal objectives are available for evaluation. The metadata record the method and, for DC3, the independent variables.
