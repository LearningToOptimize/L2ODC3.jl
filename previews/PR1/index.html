L2ODC3.jl

L2ODC3.jl trains neural-network proxies for parametric optimization problems that must satisfy hard constraints. It implements two methods on the L2OCore interface of the LearningToOptimize ecosystem:

  • DC3, Deep Constraint Completion and Correction (Donti, Rolnick & Kolter, ICLR 2021). The proxy predicts a subset of the variables, and the equality constraints are solved for the rest (exactly for affine equalities, by Newton's method otherwise), so every prediction satisfies them. Unrolled gradient steps along the equality manifold then remove the inequality violation. Training is self-supervised with a soft penalty loss.
  • FSNet, Feasibility-Seeking Neural Network (Nguyen & Donti, 2025). The proxy predicts every variable, and unrolled gradient descent on the total violation $\|h\|^2 + \|\mathrm{ReLU}(g)\|^2$ moves the prediction to a feasible point.

Problems are JuMP models with parameters. The core is framework-agnostic: any callable proxy and any ChainRules-compatible AD (Zygote is tested). Affine problems run on GPU arrays.

Installation

The registered LearningToOptimize 1.0.0 predates the L2OCore interface. Until L2OCore and L2ODC3 are registered, install L2OCore from the lib/L2OCore folder of LearningToOptimize.jl first, then this package (Julia 1.10 or later):

using Pkg
Pkg.add(url="https://github.com/LearningToOptimize/LearningToOptimize.jl", subdir="lib/L2OCore")
Pkg.add(url="https://github.com/LearningToOptimize/L2ODC3.jl")
Pkg.add("JuMP")   # to write problems

The example also uses HiGHS, Lux, Optimisers and Zygote.
